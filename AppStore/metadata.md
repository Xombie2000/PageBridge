## Product page

Name: PageBridge

Subtitle: Private Japanese page translation

Promotional text:

Read Japanese shopping sites in English automatically, with private on-device translation and no account or subscription.

Keywords:

Japanese,English,translate,Safari,webpage,shopping,offline,privacy,Japan

Description:

PageBridge automatically translates visible Japanese text on Safari webpages into English.

Translation runs on your Mac with Apple’s Translation framework. PageBridge has no account, subscription, analytics, advertising, external translation API, or custom cloud service.

Features:

• Automatically translate Japanese pages
• Enable or disable automatic translation per website
• Translate the current page on demand
• Restore the original Japanese text
• Preserve links, buttons, forms, layout, event handlers, and accessibility structure
• Translate dynamically loaded product listings without constantly rescanning the page
• Cache repeated translations locally for faster browsing

PageBridge translates Japanese text into English. Japanese and English language resources must be installed through macOS the first time you use it. Text inside images, videos, canvas content, and protected or hidden webpage elements is not translated.

Requires macOS 26 or later and the current version of Safari.
