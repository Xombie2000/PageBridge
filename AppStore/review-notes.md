# App Review notes

PageBridge contains one Safari Web Extension that translates visible Japanese webpage text into English using the macOS Translation framework.

Review steps:

1. Open PageBridge.
2. If prompted, select Download Languages and approve installation of Japanese and English translation resources.
3. Select Open Safari Extension Settings and enable PageBridge with website access.
4. Open a Japanese webpage in Safari, such as a product page on nitori-net.jp.
5. Visible Japanese text translates automatically. Select the PageBridge toolbar item to disable automatic translation for that site, translate immediately, or restore the original text.

No login or test account is required. The app contains no purchases, subscription, analytics, ads, or developer-operated network service. Website text and cached translations remain on the Mac. Network activity may occur only when macOS downloads Apple language resources or when Safari loads the user’s chosen webpage.

The broad website permission is necessary because the core purpose is to translate Japanese text on any website the user visits. PageBridge does not inspect hidden content, editable fields, scripts, styles, SVG, code, or preformatted content.
